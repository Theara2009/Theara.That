# THEARA THAT — Personal Portfolio

Pure HTML + CSS + Vanilla JavaScript.

## Included
- Responsive semantic navigation
- Hero with supplied profile photo
- About, Skills, Education, Projects, Services, Contact
- Local skill SVG illustrations
- Dark/light mode with localStorage
- English / Khmer language toggle with localStorage
- Mobile navigation
- Scroll reveal animations
- Active navigation link
- Animated meteor background
- Back-to-top button
- Client-side contact-form validation
- No frameworks or build tools

## Run
Open `index.html` in a modern browser.

The contact form is front-end only. Connect it to a backend/email service when you want real submissions.
